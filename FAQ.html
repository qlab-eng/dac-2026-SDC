Frequently Asked Questions

General

Q: Can I participate in both tracks?

A: Yes. You may enter Track 1 (ADRD Screening), Track 2 (Child Language Assessment), or both. Each track is scored independently.

Q: What is the team size limit?

A: Each team may have up to 5 members. Team members may come from different institutions.

Q: Do I need to own an NVIDIA Jetson Orin Nano to participate?

A: No. You can develop and test your solution on any machine. Final evaluation will be conducted by the organizers on the official Jetson Orin Nano hardware. However, we recommend testing your solution on ARM-based hardware or using NVIDIA's Jetson container emulation to catch compatibility issues early.

Data & Privacy

Q: Can I use additional datasets for training?

A: Yes, you may use additional publicly available datasets for training. All data sources must be disclosed in your submission report. Use of private or proprietary clinical data is not permitted to ensure reproducibility.

Q: Are there any ethical considerations for using clinical speech data?

A: The datasets provided are derived from publicly available research corpora with proper ethical approvals. Participants must not attempt to re-identify any speakers in the dataset. All processing must remain on-device during inference, consistent with the privacy-preserving design goal of the contest.

Technical

Q: What programming languages are accepted?

A: Only Python-based solutions are accepted. You may use C/C++ extensions (e.g., via ONNX Runtime, TensorRT) as long as the top-level pipeline is Python-callable.

Q: Can I use cloud APIs during inference?

A: No. The entire pipeline must run on-device without any network access during inference. Cloud APIs may only be used during the training/preparation phase.

Q: What ASR models are allowed?

A: Any ASR model is allowed, including but not limited to Whisper variants, wav2letter, Conformer, and custom models. The only constraint is that the full pipeline (ASR + feature extraction + classification) must fit within the memory and compute budget of the Jetson Orin Nano.

Q: Can I use a large language model (LLM) in my pipeline?

A: Yes, as long as the model runs entirely on-device within the hardware constraints. Quantized small language models (e.g., Phi-2, TinyLlama, Gemma-2B with 4-bit quantization) are feasible on the Jetson Orin Nano. Using an LLM is optional; lightweight classifiers are equally valid.

Q: How will latency be measured?

A: We measure end-to-end wall-clock time from raw audio input to final prediction output, averaged over 20 runs on the Jetson Orin Nano. Model loading time is excluded; only inference time is counted.

Submission

Q: What should I submit?

A: Please see the Submission page for detailed requirements. In brief: a Docker container with your full pipeline, a technical report (up to 4 pages), and a README with instructions.

Q: Will the code be open-sourced?

A: Yes. All submissions must be open-source. Finalists will be required to make their code publicly available on GitHub after the contest concludes.
